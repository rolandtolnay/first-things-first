# Plan 01: Time Block Interactions

**Subsystem:** ui | **Skills:** next-best-practices

## Context
This plan adds three interactive features to time blocks: resize by bottom-edge drag, freestyle block creation via click-drag-draw, and overlap prevention across all drop/resize/draw operations.

All three interactions use raw pointer events (not dnd-kit) with `setPointerCapture` for reliable tracking. The coexistence strategy with dnd-kit is straightforward: resize handles call `e.stopPropagation()` on `onPointerDown` to prevent dnd-kit's PointerSensor from activating; click-drag-draw operates on the grid container (not on blocks) so it never conflicts with dnd-kit.

State during interactions is local (useState/useRef) — never calling store actions on pointermove. Store mutations happen once on pointerup (commit pattern). This avoids Zustand re-renders and Dexie writes at 60fps.

Slot coordinate system: each slot is 32px tall. Position is calculated from absolute pointer position relative to the container rect (cached on pointerdown), not from cumulative deltas (avoids floating-point drift).

Overlap detection uses standard interval intersection: `startA < endB && startB < endA`. All overlap functions accept an optional `excludeId` parameter for self-exclusion (critical during resize and block movement). Maximum duration is capped at 16 slots (8 hours) or end-of-day (slot 24), whichever is less.

### 2. Add resize handle and useBlockResize hook
**Files:** `src/hooks/useBlockResize.ts`, `src/components/calendar/TimeBlock.tsx`, `src/components/calendar/TimeGrid.tsx`

Create `src/hooks/useBlockResize.ts`:
- Accepts block (TimeBlockType) and dayBlocks (TimeBlockType[])
- Local state: `isResizing`, `previewDuration` (number | null), refs for containerRect and pointerId
- `onPointerDown` handler (for the resize handle): `e.stopPropagation()` to block dnd-kit, `e.preventDefault()` to prevent text selection, `setPointerCapture(e.pointerId)`, find container via `e.currentTarget.closest('[data-slots-column]')` and cache its `getBoundingClientRect()`, record initial state
- `onPointerMove` handler: calculate newEndSlot from `(clientY - containerRect.top) / 32` using `Math.round`, compute newDuration = newEndSlot - block.startSlot, clamp with `getClampedDuration(newDuration, block.startSlot, dayBlocks, block.id)` from `@/lib/overlap`, update `previewDuration`
- `onPointerUp` handler: commit `previewDuration` to store via `updateTimeBlock(block.id, { duration })`, clear resizing state. Pointer capture auto-releases.
- Returns: `{ handleProps: { onPointerDown, onPointerMove, onPointerUp }, isResizing, previewDuration }`

- When `isResizing`: override height to `previewDuration * 32`, show time label overlay (`slotToTime(block.startSlot)` -- `slotToTime(block.startSlot + previewDuration)`) using `slotToTime` from `@/lib/utils`
- Add `touch-action: none` and `user-select: none` inline styles when resizing

### 3. Add click-drag-draw with useBlockDraw hook
**Files:** `src/hooks/useBlockDraw.ts`, `src/components/calendar/TimeGrid.tsx`, `src/components/calendar/TimeBlock.tsx`

Create `src/hooks/useBlockDraw.ts`:
- Accepts `dayIndex` (DayOfWeek) and `dayBlocks` (TimeBlockType[])
- Local state: `isDrawing`, `drawState` with startSlot/currentEndSlot/containerRect, `newBlockId` (string | null for triggering inline edit after creation)
- `onPointerDown` handler (for grid container): guard — if `(e.target as HTMLElement).closest('[data-block]')` return (skip clicks on blocks), calculate startSlot from `Math.floor((clientY - rect.top) / 32)`, verify 0-23 range, check `hasOverlap(startSlot, startSlot + 1, dayBlocks)` — if overlapping, return, `setPointerCapture(e.pointerId)`, set drawing state
- `onPointerMove` handler: calculate currentEndSlot from `Math.round((clientY - containerRect.top) / 32)`, clamp min to startSlot + 1, clamp max using `getClampedDuration(currentEndSlot - startSlot, startSlot, dayBlocks)` to respect boundaries, update local state
- `onPointerUp` handler: calculate final duration = endSlot - startSlot (min 1), call `addTimeBlock({ type: "freestyle", dayIndex, startSlot as TimeSlotIndex, duration, title: "", completed: false })`, store the returned block id in `newBlockId`, clear drawing state
- Returns: `{ containerProps: { onPointerDown, onPointerMove, onPointerUp }, isDrawing, previewBlock: { startSlot, duration } | null, newBlockId, clearNewBlockId }`

### 4. Add overlap prevention on existing drops
**Files:** `src/components/dnd/DndProvider.tsx`

Import `hasOverlap` and `getClampedDuration` from `@/lib/overlap`.

For each timegrid drop path in `handleDragEnd`, get `dayBlocks` by filtering `currentWeek.timeBlocks` by `dropData.dayIndex`:

**Goal -> timegrid:**
- Calculate `clampedDuration = getClampedDuration(2, dropData.slotIndex, dayBlocks)`
- If clampedDuration < 1: return (silent rejection)
- Use clampedDuration instead of hardcoded `2` for the duration

**Block -> timegrid (move):**
- Check `hasOverlap(dropData.slotIndex, dropData.slotIndex + block.duration, dayBlocks, blockData.blockId)` (exclude self)
- If overlap: return (silent snap-back, dnd-kit animates back)
- Otherwise proceed with existing `updateTimeBlock`

**Priority -> timegrid:**
- Same clamping as Goal: `clampedDuration = getClampedDuration(2, dropData.slotIndex, dayBlocks)`
- If clampedDuration < 1: return
- Use clampedDuration

**Evening -> timegrid:**
- Same clamping as Goal: `clampedDuration = getClampedDuration(2, dropData.slotIndex, dayBlocks)`
- If clampedDuration < 1: return
- Use clampedDuration

**From prior work:** Any new store actions in handleDragEnd must be added to the useCallback dependency array. In this case, no new store actions are needed — only imported pure functions are added.
