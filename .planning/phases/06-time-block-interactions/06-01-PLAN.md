# Plan 01: Overlap Detection Utilities

**Subsystem:** ui | **Type:** tdd | **Skills:** next-best-practices

## Context
Multiple features in this phase need overlap detection: resize must stop at occupied boundaries, click-drag-draw must prevent drawing over existing blocks, and all timegrid drops must validate available space. These are pure functions with well-defined inputs/outputs — ideal for test-first design.

Three pure functions operate on `TimeBlock[]` arrays with slot-based interval math. The core algorithm is standard interval intersection: `startA < endB && startB < endA`. All functions accept an optional `excludeId` parameter for self-exclusion (critical during resize and block movement). Maximum duration is capped at 16 slots (8 hours) or end-of-day (slot 24), whichever is less.

### 2. GREEN -- Implement overlap utilities
**Files:** `src/lib/overlap.ts`

Export three functions:
1. `hasOverlap(startSlot, endSlot, blocks, excludeId?)` — filter out excludeId, check `startSlot < b.startSlot + b.duration && endSlot > b.startSlot` for any remaining block
2. `getMaxAvailableDuration(startSlot, dayBlocks, excludeId?)` — filter out excludeId, find nearest block start after startSlot, return min(distance to nearest, 16, 24 - startSlot)
3. `getClampedDuration(requestedDuration, startSlot, dayBlocks, excludeId?)` — return max(1, min(requestedDuration, getMaxAvailableDuration(...)))

Import `TimeBlock` type from `@/types`. Minimal implementation — just make tests pass.
